# kinso-legal

Kinso mobil uygulamasının yasal ve destek sayfaları. GitHub Pages ile
yayınlanır: <https://ibrahimbilgic.github.io/kinso-legal/>

| Sayfa | Adres |
|---|---|
| Gizlilik Politikası | `/privacy.html` |
| KVKK Aydınlatma Metni | `/kvkk.html` |
| Kullanım Koşulları | `/terms.html` |
| Destek | `/support.html` |

Dil TR/EN düğmesiyle değişir; tercih `localStorage`da tutulur. JavaScript
çalışmazsa sayfa Türkçe bölümüyle okunabilir kalır. KVKK metni yalnız
Türkçedir — kanunun istediği dil odur; EN sekmesi ne olduğunu anlatıp
`privacy.html`e yönlendirir.

Dış bağımlılık yoktur: tek bir `style.css`, tek bir `lang.js`, çerez ve
izleme kodu yok.
